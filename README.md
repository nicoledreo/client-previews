# client-previews

Preview builds of work in progress. These are **not** official client sites.

- One folder per preview, named `<client>-preview`.
- Every page carries `<meta name="robots" content="noindex, nofollow">` so previews stay out of search results.
- Official client projects live in the organisation's `client-<client name>` repositories, not here.
